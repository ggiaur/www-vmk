# AI Short Memory - Architecture Summary

* **Framework:** Next.js 15 (App Router, RSC first, Server Actions).
* **Headless CMS:** Payload CMS v3 (Native Next.js 15 integration).
* **Database:** PostgreSQL 16 (`vmk_db`).
* **Object Storage:** MinIO S3 (`vmk-media`).
* **Search:** Meilisearch (`http://localhost:7700`).
* **Collections:** `Libraries`, `News`, `Events`, `Staff`, `Documents`, `Services`, `Pages`, `Media`, `Users`.
* **Globals:** `OpeningHoursGlobal`, `HeaderSettings`, `FooterSettings`, `SiteMetadata`.
