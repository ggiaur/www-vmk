# Autonomous AI Workflow & Project Phases

## 9-Phase Execution Model
1. **Discovery:** Meglévő vmk.hu elemzése, sitemap, komponenslista, tartalomleltár, SEO elemzés.
2. **Architecture:** Teljes rendszer architektúra megtervezése.
3. **Design System:** Színek, tipográfia, spacing, grid, komponens specifikációk.
4. **CMS Model:** Payload CMS v3 Collections, Globals, Blocks, Media, Workflow, RBAC.
5. **Component Library:** Atomi és moduláris UI komponensek felépítése.
6. **Frontend Implementation:** Next.js 15 alkalmazás megvalósítás.
7. **Backend Integration:** Payload CMS v3, PostgreSQL, MinIO, Meilisearch csatolás.
8. **Testing & Audit:** Vitest, Playwright, WCAG 2.2 AA, Performance, SEO audit.
9. **Deployment:** Docker Compose, CI/CD GitHub Actions.

## Expected Autonomous Behaviour
* **Soha ne várj újabb utasításra**, ha egy következő logikus lépés egyértelműen következik az előzőből.
* Önállóan haladj tovább a projekt következő fázisára.
* Ha több lehetséges megoldás van, válaszd azt, amelyik:
  - egyszerűbb;
  - hosszabb távon fenntarthatóbb;
  - jobban tesztelhető;
  - kisebb technikai adósságot eredményez.
* Minden jelentősebb döntés előtt röviden indokold a választott irányt.
* Minden elkészült fázis végén készíts összefoglalót (elkészült elemek, kompromisszumok, következő lépés).
